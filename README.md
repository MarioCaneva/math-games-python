# 🎮 Math Games in Python (Jupyter Widgets)

This project includes **three interactive math games** built with Python and Jupyter widgets. The games are designed to reinforce coordinate plotting, algebra solving, and quadratic function intuition in a fun, visual way.

---

## 🧠 Games Included

### 1. 📍 Scatter Plot Game
- Random points appear on a coordinate grid.
- Players must guess their coordinates (x, y).
- Get close (within ±1) to earn points!
- Difficulty increases with larger graphs and more points.

### 2. ➕ Algebra Practice Game
- One-step and two-step algebra problems generated randomly.
- Includes positive and negative integers.
- Input can be integers or fractions (e.g., `-3`, `1/2`).
- Score is tracked live as you play!

### 3. 🚀 Projectile Game
- A wall appears randomly at a distance and height.
- Use sliders to adjust a quadratic equation (parabola) that clears the wall.
- Choose between:
  - **Interactive mode**: Use sliders to change `b` and `c` values.
  - **Manual mode**: Type in your own `a`, `b`, `c` for the launch formula.
- Visual feedback tells you whether the rocket cleared the wall or crashed.
